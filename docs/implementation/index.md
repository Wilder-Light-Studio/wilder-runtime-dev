# Implementation Documentation

What this is. This page is the landing page for the internal, project-facing
documentation set. [README.md](README.md) gives the reading order.

## MVP (governs current work)

- [MVP-REQUIREMENTS.md](MVP-REQUIREMENTS.md): what must be true for the MVP,
  including the ontology, Concepts and AI access.
- [MVP-SPECIFICATION.md](MVP-SPECIFICATION.md): how the MVP requirements are met,
  plus the plausibility constraints and phases.
- [MVP-COMPLIANCE-MATRIX.md](MVP-COMPLIANCE-MATRIX.md): every MVP requirement with its
  proving test and current status.

## Long-term reference

- [REQUIREMENTS.md](REQUIREMENTS.md): the full requirements. The MVP files cite it.
- [SPECIFICATION.md](SPECIFICATION.md): the full specification. The MVP files cite it.

## Working guides

- [DEVELOPMENT-GUIDELINES.md](DEVELOPMENT-GUIDELINES.md): the change workflow.
- [COMMENT_STYLE.md](COMMENT_STYLE.md): source comment and documentation style.
- [ND_DOCS_CHECKLIST.md](ND_DOCS_CHECKLIST.md): the Neurodivergent (ND) documentation
  checklist.
- [COSMOS_UNINTEGRATED_TERMS.md](COSMOS_UNINTEGRATED_TERMS.md): terms not yet
  integrated into the requirements.
